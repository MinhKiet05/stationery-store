Query và bảo mật
Thêm @tanstack/react-query 5.108.4 và dependency query-core; một QueryClient ở module và provider tại main.tsx. Cache RAM, không persist dữ liệu admin/user. Mặc định staleTime60s, gcTime15m, focus/reconnect chỉ refetch nếu stale. Read retry tối đa1 cho network/408/429/502/503/504; không retry AbortError/400/401/403/404/409/422. Mutation retry=false.

Key public: ['public', resource, params] cho products/productDetail/inventory/reviews/categories/vendors. Params gồm handle/ID, page/size, keyword, category, brands, giá, rating, stock, sale, sort hoặc related category.
Key private: ['session', opaque-generation, resource, params] cho currentUser/profile/cart/orders/recommendations. CurrentUser có API base; orders có page/size/search/status hoặc summary. Không chứa JWT.
Key admin: ['session', generation, 'admin', canonicalPath] chứa đủ query parameters/range/groupBy. Modal dùng loader identity riêng và ID, staleTime/gcTime=0; mở lại luôn đọc snapshot/version mới. Không refetch ngầm detail khi đang quyết định nghiệp vụ.
TTL: categories/vendors15m; products3m; detail/reviews2m; vouchers/stats1m; cart/orders/returns/users30s; inventory15s; currentUser/profile5m. Backend vẫn quyết định giá/tồn kho/quyền.

Giữ nguyên AdminRoute/nested layout, single-flight và TTL xác minh ADMIN cũ. CurrentUser query chỉ phục vụ hiển thị, không thay authorization proof. Logout/account switch đổi generation, cancel/remove private queries, clear mutation cache; role revoked xóa admin queries. Response cũ bị loại khi đổi phiên, kể cả lúc đọc body. Không thay SecurityConfig/JWT thành permitAll hoặc cache quyền trên backend.

Dashboard và prefetch
Tất cả trang/widget dùng chung useQuery adapter. Có data thì giữ lại khi background fetch/lỗi và hiện thông báo nhẹ; skeleton khi chưa có data. Đổi page/filter không lấy trang trước làm kết quả trang mới. Header/Sidebar giữ nguyên.
Hover/focus một số menu chỉ prefetch sau khi backend xác minh ADMIN cho đúng token hiện tại. Product link dùng cùng detail key. Debounce180ms, tối đa1 prefetch chạy đồng thời, hủy ý định khi rời link, chỉ đọc thiếu/stale. Không prefetch users, toàn catalog, mọi Dashboard page sau login hoặc next-page không có nhu cầu rõ ràng.

Optimistic và invalidation
- useCartMutation hỗ trợ API add/quantity/remove sẵn có; UI sản phẩm hiện dùng add. Cancel read, snapshot, cập nhật RAM/header ngay nếu có cart, dùng response chính thức, rollback và GET reconcile khi lỗi. Khóa theo phiên chặn ghi trùng từ hai component; chỉ mở sau reconcile. Không rollback vào phiên mới. Toast thành công sau backend acknowledge.
- Guest cart/wishlist vẫn ghi localStorage đồng bộ, không tạo API wishlist giả. Storage lỗi giữ trạng thái thực. Wishlist tái sử dụng public detail cache, tối đa4 request đồng thời.
- Checkout/order decisions/cancel/return approve/receive/restock/inventory/roles/delete/import quan trọng chỉ pending và backend-confirmed. Checkout network/5xx không rõ kết quả khóa submit lại và dẫn tới lịch sử để đối chiếu. Không thêm thanh toán/hoàn tiền tự động.
- Write thành công đánh dấu stale đúng domain; inactive pages không đồng loạt refetch, callback modal refresh widget đang dùng. Product -> list/detail/inventory/product stats; order -> orders/cart/inventory/returns/vouchers/overview; return -> orders/returns/overview, chỉ restock tác động inventory; coupon -> voucher; review -> reviews/rating sản phẩm; user -> user/profile/currentUser/stats liên quan. Không invalidate toàn ứng dụng.
- Merge guest cart khi login cancel read cũ và lưu cart response vào cache; profile update lưu hồ sơ và refresh identity đang dùng.

Backend và contract
/api/products/search thêm mode catalog=true với brands/rating/inStock/onSale và DB pagination/sort; size<=100, whitelist sort, escape LIKE, ID tie-breaker. Tìm kiếm tiếng Việt nhiều từ qua title/vendor/category bằng translate, không cần extension DB mới. Giá fallback priceMin như catalog cũ. Không có catalog flag thì contract search legacy giữ nguyên.
/api/orders/my-orders giữ response list cũ khi không có page/summary. Mode page trả content/totalElements/totalPages/statusCounts; summary=true chỉ aggregate, không hydrate orders/items. Username lấy từ Authentication, không nhận user ID từ client. Search dùng EXISTS thay vì collection fetch join với pagination. Banner/OrderHistoryTab đã dùng summary/page.
AdminProductRepository.statistics gộp ba count thành một aggregate, cùng filter/low-stock definition. Không đổi relationships thành EAGER.
Giữ pool max4/minIdle0/connectionTimeout10s, open-in-view=false, batch_fetch_size32, show-sql=false. Không tăng pool khi chưa biết Supabase quota. Chưa thêm Caffeine vì chưa đo được lợi ích sau khi bỏ request thừa; tránh cache eviction/transaction race chưa cần thiết. Không thêm Redis/Kafka/Redux.
